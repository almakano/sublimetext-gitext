# GitExt

Thanks for installing GitExt.

- Right-click in the editor or on a file/folder in the sidebar and open the **GitExt** submenu.
- `GitExt: diffTab` shows the unstaged changes in the current tab.
- The diff opens automatically for files in Git repositories. Disable it with `"show_gitdiff_on_open": false` in **Preferences → Package Settings → GitExt**.

Git must be available in `PATH`.
